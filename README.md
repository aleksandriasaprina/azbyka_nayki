### Азбука науки

Образовательный сайт, который помогает разобраться в современной науке без паники. Для школьников 8–11 классов, студентов первых курсов и всех, кто хочет понять, чем занимаются учёные.

**Что внутри:**
- Три направления «за 10 минут»: астрономия, ядерная физика, ИИ.
- Мини-курс «Научный метод» — 5 коротких уроков.
- Словарь терминов с поиском.
- Чат-бот «Спроси у науки» — отвечает на простые вопросы и ведёт к нужному разделу.

**Стек:** HTML, CSS, JavaScript. Планируется подключение API для чат-бота.

**Статус:** учебный проект, в разработке.
